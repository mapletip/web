Loader bytes are UTF-8 bytes of `JSON.stringify(projected MonsterDetailView)`. HTML sizes are the uncompressed `curl` response-body byte counts from direct GETs to the final local Vite SSR server at `127.0.0.1:3003`; requests did not ask for compression, and the bodies include development and TanStack hydration bootstrap. The reproducible command form was `curl -sS -o /tmp/<record>.html -w '%{http_code} %{size_download}\n' http://127.0.0.1:3003/<canonical-route>`. Each loader made four SDK requests: the release manifest (886 B), build index (33,542 B), build product manifest (`cw-launch` 17,429 B; `gms-v83` 189,787 B), and the bounded per-monster page pack shown above. The trace contained no whole-build artifact, catalog, or browse-artifact request. Browser image requests and the document request are excluded from the four SDK requests.

All five direct route requests returned HTTP 200. The GMS Balrog and White Yeti/King Pepe records project zero known maps in this release.

## 10.3 Keyboard and accessibility

- **Keyboard:** passed on Green Mushroom. Tab navigation reached the skip link, site navigation, breadcrumb, stat tooltips, section links, location controls, drop accordion, and certainty disclosure. Enter opened “View all 35 maps”; Escape closed it and restored focus to the trigger. The Drops accordion collapsed and reopened with `aria-expanded` changing accordingly. Enter opened the certainty dialog and Escape closed it.
- **Accessibility tree:** inspected Chrome’s computed accessibility tree for the page landmarks, breadcrumb, page heading, stat controls, section navigation and its counts, and the section content. This is a browser accessibility-tree inspection, not a screen-reader pass.
- **axe:** WCAG 2 A/AA tags produced 0 violations, 29 passes, and one incomplete contrast check for the Mantine segmented-control pseudo-element, whose rendered background axe could not determine. This was not a violation.
- **Actual screen reader:** not run. No Orca, NVDA, `speech-dispatcher`, `espeak`, or `espeak-ng` executable is installed in this environment. `Summoned by` is absent from all six acceptance records, so that optional live section was not available to traverse.
