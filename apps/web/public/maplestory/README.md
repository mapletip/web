# MapleStory assets

Staging area for MapleStory game assets served by the app. All MapleStory
artwork belongs here, under a subdirectory describing where it is used —
`navigation/` holds the header category icons.

These files are **not** covered by the repository's GPL-3.0 licence. MapleStory
and related game content are property of NEXON and/or their respective rights
holders. They are kept here at icon size for identification in a fan reference
project. See the notice at the top of `LICENSE`.
